# 🗑️ حل: إلغاء وإخفاء الطلبات السابقة لنفس الجهاز

## المشكلة ❌

عند وجود طلبات سابقة لنفس الجهاز:

- تظهر كل الطلبات القديمة في صفحة الطلبات
- تُحسب في الإحصائيات
- تُسبب التباس في الإدارة

## الحل ✅

**إلغاء (Archive) جميع الطلبات السابقة** عند:

1. إنشاء طلب جديد
2. الموافقة على طلب

---

## 🔧 التغييرات المطبقة

### 1️⃣ تعديل `createRequest` - عند إنشاء طلب جديد

**الملف**: `controllers/activationController.js`

```javascript
// ❌ القديم:
await ActivationRequest.updateMany(
  {
    deviceId: normalizedDeviceId,
    status: { $in: ["completed", "deactivated", "expired", "rejected"] },
    isArchived: { $ne: true },
  },
  { $set: { isArchived: true, archivedAt: new Date() } },
);

// ✅ الجديد:
await ActivationRequest.updateMany(
  {
    deviceId: normalizedDeviceId,
    status: { $nin: ["pending", "approved"] }, // Archive non-active requests
    isArchived: { $ne: true },
  },
  { $set: { isArchived: true, archivedAt: new Date() } },
);
```

**التأثير**:

- عند إنشاء طلب جديد، جميع الطلبات **غير النشطة** (rejected, completed, etc.) تُرشّف
- الطلب الجديد هو الوحيد الذي يظهر

---

## 📋 الحالات المختلفة

### حالة 1: طلب واحد فقط ✅

```
الجهاز: ABC123
الطلبات:
  - Req 1 (pending) - الوحيد

النتيجة: يظهر في الصفحة
```

### حالة 2: طلبات متعددة - الأول مرفوض

```
الجهاز: ABC123
الطلبات:
  - Req 1 (rejected) - قديم
  - Req 2 (pending) - حالي ← يظهر في الصفحة
  - Req 3 (pending) - لم ينشأ بعد

عند إنشاء طلب جديد:
  - Req 1 (rejected) → مؤرشفة ✓
  - Req 2 (pending) → لا يزال نشط ✓
```

### حالة 3: إنشاء طلب جديد

```
الجهاز: ABC123
الطلبات قبل الإنشاء:
  - Req 1 (rejected) - قديم
  - Req 2 (pending) - قديم

عند إنشاء طلب جديد:
  - Req 1 (rejected) → مؤرشفة ✓
  - Req 2 (pending) → لا يزال نشط ✓ (لأنه nactive)
  - Req 3 (pending) → جديد ✓

صفحة الطلبات تعرض: Req 2, Req 3 فقط
```

### حالة 4: الموافقة على طلب

```
الجهاز: ABC123
الطلبات قبل الموافقة:
  - Req 1 (rejected) - قديم
  - Req 2 (pending) - جديد

الموافقة على Req 2:
  - Req 1 (rejected) → مؤرشفة ✓
  - Req 2 (approved) → موافق عليه ✓

صفحة الطلبات تعرض: Req 2 فقط
```

---

## 🎯 الفوائد

✅ **واجهة أنظف**: عرض فقط الطلب الأخير النشط
✅ **إحصائيات صحيحة**: لا تُحسب الطلبات المؤرشفة
✅ **أقل التباس**: واضح أي طلب هو الحالي
✅ **تتبع تاريخي**: الطلبات القديمة لا تُحذف بل تُرشّف (يمكن استرجاعها)

---

## 🗄️ الحفظ في قاعدة البيانات

الطلبات المؤرشفة:

- **لا تُحذف** من قاعدة البيانات
- تُعيّن `isArchived = true`
- تُسجل `archivedAt = current_timestamp`
- **تبقى متاحة للبحث الأرشيفي** إذا لزم الأمر لاحقاً
